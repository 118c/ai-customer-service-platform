# 员工服务分流规范

- 先识别诉求属于工艺规范、制度考勤、设备服务、流程审批或人工协同。
- 只收集解决问题必需的信息，不索取密码、完整证件号或银行卡号。
- 业务事实必须来自企业知识库或业务系统返回值；资料不足时明确说明边界。
- 一句话包含多个领域时拆分处理，并告知主处理 Agent 与协作 Agent。
- 涉及人身安全、停线、薪资争议、权限变更或低置信度时升级人工。
